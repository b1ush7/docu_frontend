# P0 / P1 修复（2026-10-20）

## 已完成

- XLSX 编辑器首次挂载即读取结构，切换版本重新读取；提交单元格编辑后不会调用浏览器的 `window.close()`。
- DOCX、XLSX、图片人工编辑完成后，刷新文件元信息、打开明确输出版本、更新 URL 并退出原 AI/任务上下文；刷新页面恢复该版本。
- 模板生成后打开新文件最新版本，文件名、预览和 URL 保持一致，清空原任务与会话选中状态。文件切换期间阻止并发导航。
- OCR 识别完成后按指纹读取服务端校正；弹窗重开时，使用内存中的最近一次识别信息读取服务端校正，无需重复识别。整页刷新后没有识别指纹时，需要显式识别一次再读取校正（现有接口要求指纹）。
- OCR 导出下载当前可见文本草稿，保留空白页的位置，不重新调用 OCR；保存文本时保留已经存在的表格校正。AI 整理只允许处理已保存且未继续修改的校正，首次未修改的识别结果也可显式保存。
- 校正读取的 404 作为尚未保存处理；其他读取失败会阻止保存，避免覆盖尚未读取的校正。
- OCR、模板、所有人工编辑器和管理员文件查看增加作用域与请求序号保护。切文件、切版本、关闭或卸载后，旧响应不能更新状态、显示错误、触发下载或发出编辑成功事件；同一编辑请求执行中阻止重复提交。
- SSE 解析支持 LF / CRLF、跨分片事件、多行 data 和最终响应补读；流中断后复用原幂等键回退，卸载后中止连接并忽略迟到增量。
