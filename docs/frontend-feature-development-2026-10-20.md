# 前端剩余功能开发（2026-10-20）

范围：补齐上一轮前端扫描列出的功能缺口。本轮仅修改前端，不涉及后端开发、部署、数据库迁移或 CI 配置。

## 本轮代码实现

| 功能 | 用户入口与行为 |
| --- | --- |
| 编辑草稿 | DOCX 段落、格式、表格、目录/图片/页眉页脚/脚注、XLSX、图片编辑、模板生成、AI 指令、OCR 校正和 PDF 转换设置支持本标签页草稿缓存、恢复及删除；关闭和切换前提示未提交修改 |
| 草稿隔离 | 按账号、编辑器、文件、版本隔离；OCR 额外按识别指纹隔离；提交某类操作后清除该类旧版本草稿，保留其他未提交页签内容 |
| 操作保护 | 保存、转换、识别和上传期间阻止切换；提交期间禁用编辑；页面离开时使用浏览器原生提醒 |
| 文件/任务列表 | 搜索或选中文件变化时丢弃旧请求响应；翻页成功后才推进页码，失败可重试 |
| 完整任务搜索 | 未选文件时按页读取全部任务后过滤，显示读取进度；选中文件时搜索该文件完整任务历史 |
| OCR 结果恢复 | 在 sessionStorage 保留原识别结果与指纹；重新打开或刷新后读取对应服务端校正，不自动调用识别；保留校正读取失败的重试入口 |
| 图片选择 | DOCX 内嵌图片和 XLSX 内嵌图片提供现有图片搜索、分页、鉴权缩略图、历史版本选择及 PNG/JPEG 上传；上传后自动填入文件与版本 |
| PDF 内容 | PDF 预览新增“文字与页面分类 / 转 DOCX”页签，显示文字/扫描/混合/空白页统计、按类型和文字过滤、逐页原生文本和文本导出 |
| PDF 转换 | 支持可编辑/版面取向、OCR 语言及转换说明；仅允许所读最新版本转换；成功后打开新版本；同步请求超时设为 120 秒 |

## 运行边界

- 草稿和 OCR 原结果使用 sessionStorage：同一标签页刷新可恢复，关闭标签页后不保证保留；不保存登录 Token。浏览器存储失败或额度不足时显示提示。
- 草稿不会自动提交，也不会套用到其他账号、文件或新版本；恢复旧版本草稿时应打开对应旧版本。
- 图片列表依据文件当前扩展名筛选 PNG/JPEG；分页来自现有文件列表接口，某页可能没有图片。缩略图使用鉴权下载的 Blob URL，切换和销毁时释放。
- PDF 原生文字读取不执行 OCR。扫描内容识别仍在“OCR 识别与校正”中操作。
- 指定 OCR 语言的 PDF 转换使用现有 PDF 同步转换接口；异步任务创建接口未声明 OCR 语言，本轮没有向其添加不支持的参数。
- 同步转换超时或网络中断后，服务端可能已完成处理，应先查看最新版本再决定是否重试。
